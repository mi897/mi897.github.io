Module 5: Cohomology loss, ToM decoders, avoiding collapse about 14 hours

This module adds the three auxiliary training terms: the cohomology loss pulls consensus embeddings together, the theory-of-mind decoder keeps them informative, and the directional loss decides which arm moves toward which. You build them first on a toy problem, where failures are cheap to see.

L_tot = α · L_nc + β · L_tom + γ · L_conf

The paper reports no values for alpha, beta or gamma. Its equation also leaves out the diffusion denoising loss, which is presumably added separately.

What each term does, per the paper

  • Cohomology loss (L_nc). Summed squared difference between the two consensus embeddings on each edge.
  • ToM loss (L_tom). For each ordered pair of arms, a multi-head attention decoder uses arm u's consensus embedding as the query and arm v's ego embedding as keys and values. It regresses v's true ego embedding with a squared L2 loss. Each direction has its own network.
  • Confidence and directional loss (L_conf). A small network outputs a confidence between 0 and 1 for each arm. The lower-confidence embedding is pulled toward the higher-confidence one, and each edge's error is scaled by 1 plus the confidence gap. An entropy term keeps confidences away from 0 and 1 early in training.
Why L_nc alone fails (my reasoning, not the paper's): two constant embeddings agree perfectly, so the cheapest way to reduce the loss is to throw away all information. The ToM term forces the consensus embedding to still predict something about the partner.

Open points to resolve yourself: read literally, the paper's decoder receives the true target as keys and values, which would let it copy the answer, and the indicator functions in the directional loss are not differentiable. Check the paper's equations and the official code, then record your choice.
