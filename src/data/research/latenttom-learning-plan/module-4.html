Module 4: Sheaf theory for engineers about 12 hours

A cellular sheaf on a graph says that each node holds data and each edge states how its two endpoints' data must relate, and all the paper's math follows from one matrix, the coboundary. You need only linear algebra here, no algebraic topology background.

What to learn

  • Stalks and restriction maps. Each node and edge gets a vector space. Each node has a linear map into the space of each edge it touches.
  • Coboundary. For an edge between u and v, the coboundary measures their disagreement after translation into the edge space.
  • Global sections. Assignments with zero disagreement on every edge form the kernel of the coboundary. The kernel is called H⁰.
  • Laplacian. The sheaf Laplacian is the coboundary transposed times itself, and its energy is the total squared disagreement.
  • Diffusion. Repeatedly stepping x to x minus eta times L x drives the system toward a global section.
(δx)(e) = ρ_{u→e} x_u − ρ_{v→e} x_v
L = δᵀδ
xᵀ L x = Σ over edges e=(u,v) of ‖ ρ_{u→e} x_u − ρ_{v→e} x_v ‖²

The last expression is exactly the paper's L_nc. The paper calls it a first-order cohomology loss, but it is the squared size of the coboundary, an energy, and it never computes H¹.

The Boids link: a boid steering toward its neighbors' average heading is graph-Laplacian consensus with the trivial sheaf. A sheaf adds a translation on each edge, for example when two agents use different reference frames.
