Module 6: Decentralized execution and Laplacian inference about 8 hours

At run time the arms either act alone or swap consensus embeddings and average them, and that update is simple enough to analyze completely. Both modes use the same trained policies, and the second needs no retraining.

The two modes in the paper

  • No communication. Fully decentralized. Each arm sees only its own sensors, which include a view of the other arm.
  • With communication. Before each inference step the arms exchange consensus embeddings once, then apply the update below for T iterations. The paper does not report eta or T.
h_u ← (1 − η) h_u + η h_v
h_v ← (1 − η) h_v + η h_u

Two facts to derive yourself. The sum of the two embeddings never changes, so the pair keeps its midpoint. The gap between them is multiplied by 1 minus 2 eta each round, so eta of 0.5 closes it in one step. With two arms, one exchange gives both sides everything they need to run all T rounds locally. That last point is my inference from the paper's description.
