Module 1: Diffusion models and diffusion policy about 12 hours

Diffusion policy treats action generation as denoising, so one network can represent several valid ways to do the same task. LatentToM's per-arm policies are diffusion policies, and its code is a fork of the Diffusion Policy repository.

What to learn

  • The forward noising process, the noise-prediction loss below, and sampling. Then DDIM, which cuts the number of inference steps.
  • Conditioning: the denoiser receives an observation embedding and the noise level k.
  • Action chunking: predict a horizon of future actions, execute the first few, then re-plan.
